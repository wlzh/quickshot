# QuickShot 1.3.11 本机自测版

基于现有 1.3.10 本机开发版，保留截图工具栏、标注和 OCR 等已有功能。此版本用于本机自测，未发布到公开更新源。

- 进入滚动截图模式后，框选区域并松开鼠标即开始采集；已有选区时，按滚动模式快捷键立即开始。
- 滚动结束后，浮窗的「复制」会把完整拼接图写入剪贴板并关闭浮窗；「进入主窗口」会打开编辑器，原有回车和 Esc 操作保留。

自测时，先在一张长网页上框选并滚动，点击「复制」，粘贴确认图像包含滚动后新增的内容，且 QuickShot 主窗口未弹出。再做一次滚动截图，点击「进入主窗口」，确认可以预览、编辑并保存长图。

安装和签名校验按 [本机更新流程](local-macos-release.md) 执行。
